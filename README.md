# Local Lens Dashboard

A small, dependency-free dashboard for scanning upcoming community events, ticket costs, and availability at a glance.

## Run locally

Serve the repository with any static file server, then open `index.html`. For example:

```bash
npx serve .
```

## Quality checks

```bash
npm test
npm run check
```

The starter uses plain HTML, CSS, and JavaScript so it is easy to adapt for another city or connect to a real events feed later.
